# Screen index

Captured November 5, 2026. Native and browser evidence are explicitly separated. Images are direct captures, not mockups.

All seven native navigation destinations are represented: dashboard, meal plan, recipes, recipe detail, add recipe, edit recipe, grocery and settings (add/edit share one route). Additional states include validation, ingredient/meal/grocery dialogs, week view and preferences.
